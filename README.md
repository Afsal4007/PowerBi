# Tyre Retail Sales & Inventory Analysis | Power BI

## Project Overview

The **Tyre Retail Sales & Inventory Analysis** project is an interactive Power BI report designed to explore retail sales performance alongside inventory and supplier information. It brings key business information into one report to help users review performance, investigate sales patterns, and monitor stock.

This project demonstrates how Power BI can be used to turn retail data into a clear, interactive business reporting experience.

## Business Objectives

- Review overall retail sales performance using summary metrics.
- Explore sales results in more detail through a dedicated sales analysis page.
- Monitor stock levels and review inventory by product and category.
- Analyse supplier-related inventory information to support purchasing and replenishment decisions.
- Make it easier to identify areas that may need further investigation.

## Report Pages

The Power BI file contains the following report pages:

| Page | Purpose |
|---|---|
| **Executive Summary** | High-level overview of key business performance metrics. |
| **Sales Analysis** | Detailed view of sales performance and related patterns. |
| **Inventory & Supplier Analysis** | Inventory and supplier-focused analysis to support stock monitoring. |
| **Cards** | A page containing card-style report elements. |

## Key Questions This Report Can Help Explore

- How is the business performing across its sales metrics?
- Which products or categories contribute most to sales?
- How is inventory distributed across products and categories?
- Which suppliers are associated with current stock?
- Which products may require closer stock-level monitoring?

*The answers depend on the data and filters selected in the report. This README intentionally does not state numerical results that have not been verified.*

## How to Use the Report

1. Download or clone this repository.
2. Open `Tyre Retail Sales & Inventory.pbix` using **Power BI Desktop**.
3. If Power BI prompts for a data source or credentials, configure the source as required.
4. Navigate between the report pages.
5. Use available slicers, filters, and visual interactions to explore the data.

> **Note:** Data-source paths and credentials may need to be updated when opening the file on another computer. Do not commit passwords, access tokens, or confidential business data to GitHub.

## Limitations

- Findings are dependent on the completeness, accuracy, and refresh status of the underlying dataset.
- The report's results reflect the available fields, measures, filters, and modelling choices.
- Stockout risk, reorder quantities, profitability, or supplier performance should only be assessed where the dataset and calculations support those analyses.
